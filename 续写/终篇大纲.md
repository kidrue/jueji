# 《爵迹》亚斯蓝终篇总纲

## 创作约定

接续本地《爵迹》第168回以及已有续篇第169回，新增第170—193回。每回先列大纲再写正文，正文去空白后3000—4000字，目标平均3400字。终篇完整解决亚斯蓝主线，另外三国只作为背景。

本文是本次续篇的创作设计。原文未揭晓的真相在此给出新增解释，不将这些解释倒写成原文已确认的事实。用原创语言继承多线切换、空间与光色描写、能力相克、情感回响等高层技法。

主题：人可以渴望力量、害怕失去，也可以在这些愿望之外，选择保护他人。最终终止将人视为可替换材料的统治；归来的银尘成为普通人，麒零学会平等地与他相处。

## 三阶段与时间

第一阶段170—177：遗迹突围与救命，约三天。第二阶段178—185：调查、求救与选择，约十二天。第三阶段186—192：决战、救援完成与战后清理，约四天；193在次年初春，收束日常。时间位面内外分别计时，不能把洞内几息与外界整日混为一谈。

## 固定结局

银尘保有完整本人记忆与人格，肉身能正常生活，永久失去全部魂力和王爵身份；与麒零成为相互选择的平等伙伴，维持原有师徒与亲友情谊，不强行新增明确恋爱关系。麒零仍有有限魂力和既有天赋，拒绝接任支配者。

幽花保留永生皇血，自主参与公开资料和救助；莲泉摆脱黑血，失去永生，保留驭兽与有限生命。神音、霓虹离开处刑体系，停止以折磨换取成长。吉尔存活、有伤，放弃王座，离开帝都。艾欧斯留在政治治理岗位，承认旧罪、公开资料并接受监督。

寒霜似、呪夜、漆拉及三祭司死亡。原已死亡的幽冥、特蕾娅、西流尔、鬼山缝魂、东赫不复生。格兰仕与饕餮身份得到确认，其苦难在187回终止，故人被纪念。

## 阶段交接契约

177回结束：所有主角在格兰尔特皇宫地下秘密冰室及相邻藏书房；银尘冰封无意识，灵魂微弱但受护；吉尔疲惫且不能无限使用大术；麒零已经继承王爵，仍不熟练。幽花保永生，莲泉有两系共四套回路，黑血只能暂时压制。三筒齐全，母亲手记密码已解。敌人知道他们逃了，不知冰室准确位置。神音、霓虹尚在隐山宫；漆拉仍敌对、受伤而存活。

185回结束：完整计划和三个控制节点定位已有可靠证据，天格部分地方分路支持公开档案；银尘已醒过一次又回冰封，知情同意剥离方案。神音、霓虹加入合作，外放无感仅小范围短时、必须付出防护与痛觉代价；莲泉黑血仍可能反噬，剥除永生方案已经提出。漆拉因名单动摇但还未投诚；三祭司发动清除令。麒零、吉尔准备进入核心，幽花与莲泉护阵，艾欧斯统筹撤民并保护冰室。

独立分段撰写应遵守此契约。对前段新增的次要细节以最终衔接校订为准，不改变这些主要状态。
## 实际分场大纲（169—193回）

### 第一百六十九回：未熄之门

1. **白色地狱门外**：麒零仍困在漆拉的时间屏障中。失去银尘的感应后，他从盲目冲撞转向观察，寻找尚能采取的行动。
2. **鲜血祭坛**：幽花借已经修复的聚魂玉汇聚周围魂雾，维持输血并尝试救助莲泉；魂力补充却让莲泉体内的黑血再次活跃。
3. **白色地狱门外**：呪夜察觉变化，准备返回祭坛。麒零得知幽花还活着，将救出同伴作为眼前目标，尝试调整迟滞中的动作，仍未突破屏障。
4. **白色地狱内**：黄金源泉附近出现微弱金光，向石柱移动，白色草丝短暂停滞。银尘没有清醒或主动反应；异常的来源暂不揭晓。

### 第一百七十回：迟滞者

1. 白色地狱门外，漆拉撤换麒零所在的迟滞位面，依祭司保留继承者活体的要求将他移送祭坛；麒零只能记住断续可见的动作。
2. 转移途中，寒霜似要求剥夺魂器，漆拉以保持新爵印完整为由保留银钩，麒零把银钩藏入掌心伤口处。
3. 鲜血祭坛，恢复正常速度的麒零发现幽花仍在放血、铜灯仍在供雾；他压住救银尘的冲动，先稳住幽花。
4. 漆拉留下封闭出口的棋子，呪夜借莲泉的眼睛核对俘虏；麒零发现地面血纹与灯的浓雾互相牵连，准备有限应对。

### 第一百七十一回：血灯不灭

1. 祭坛上，莲泉失控的锁链击向幽花；麒零借银钩唤出雪刺，挡住攻击，但无法同时维持大范围防护。
2. 幽花通过铜灯旋钮减弱局部供雾，观察黑血随之迟缓，再恢复自身修复所需的最低供雾；麒零协助清理血沟。
3. 呪夜迫使莲泉攻击麒零，幽花主动接住受伤的同伴；两人利用石碑遮挡与雪刺甲壳相互救助。
4. 他们尝试呼唤莲泉，短暂犹豫仍被黑血夺回；麒零把魂器落在灯与血纹之间，准备改变魂雾先后流向。

### 第一百七十二回：被借走的眼睛

1. 寒霜似返回祭坛，借莲泉已接入的视路观察石碑背后，呪夜通过黑血指令调整锁链，展示两种控制的配合。
2. 祭坛石盖开启，幽冥、特蕾娅遗体被送入下方容器；黑血牵动尸身而不出现生命恢复，麒零确认敌人也被当作材料。
3. 麒零利用已储存魂器分段吸纳与释放附近魂雾，幽花调节聚魂玉，使莲泉附近的供给变动，造成局部指令错位。
4. 代价使麒零无法持续多点操控，两人收拢尝试；深处的白草连接处传来反常震颤，寒霜似将视线转向下层。

### 第一百七十三回：石柱上的微光

1. 白色地狱内，源泉残余沿吞噬网抵达石柱，吉尔伽美什暂时苏醒，先护住银尘尚未散失的完整灵魂。
2. 吉尔将有限余力送入白草已贯通的吞噬网，只发动一次反向冲击，扰动漆拉的原位面锚点。
3. 祭坛外的控制短暂错乱，幽花守住血门，麒零以存储魂器传递少量现有魂雾，沿松动的下层通路接近洞口。
4. 雪刺遮挡敌方追击，麒零亲眼看见银尘遗体与护魂微光，确认灵犀仍然断裂；吉尔要求立刻准备有限撤离。

### 第一百七十四回：归路

1. 洞内短暂救援与洞外漫长等待形成压力；麒零以门外少量魂雾支撑吉尔脱离石柱，银尘遗体被完整托起。
2. 吉尔沿已经松动的锚点撬开短距离撤离通路，漆拉阻拦而受伤；幽花保持祭坛血门，直到同伴抵达。
3. 莲泉争得片刻自主，替幽花卡住碑内刀轴并为上层魂兽让出退路；黑血仍在，众人无法留在遗迹追击敌人。
4. 雪刺遮挡、苍雪之牙承载，众人带银尘撤往雷恩；吉尔战力耗尽，敌方仍能追踪他们的大致逃离方向。

### 第一百七十五回：封在冰里的名字

1. 雷恩骑士以筒底预留的后备路引带众人离城，经密船与宫外转接，在第三日黎明抵达格兰尔特地下冰室。
2. 艾欧斯接手护魂，先以冰封延缓散失；医官分开检验肉身损伤与魂路损伤，吉尔只能提供所见事实。
3. 微量引雾试验使银尘旧魂路边缘再次崩裂，证明永久损毁不能随肉身修补恢复；麒零接受暂时不唤醒他。
4. 莲泉进入相邻隔离间，外联暂时受抑而黑血未除；麒零为冰床写下银尘的名字，第一筒被封存等待另外两筒核验。

### 第一百七十六回：三封未寄出的信

1. 格兰尔特与国境骑士先后按后备路线进入地下藏书房，三人核对刻痕、封蜡与行程，三个金属筒终于到齐。
2. 迭代名单、黑血实验记录、控制阵图分开摊读，使用编号、旧印和麒零记录的容器位置互证，保留尚不能解释的缺项。
3. 特蕾娅的附信表明她以资料对祭司留后手；材料中的天格强制观测令与幽冥执行回签同时呈现，不因死亡删去罪行。
4. 众人登记并留存完整证据，幽花发现投喂批号对应母亲手记的未解页，准备按原有魂力点密码继续解读。

### 第一百七十七回：永生者的女儿

1. 地下藏书房，幽花按母亲第一页魂力点形成的三、六、四序列逐字抽取，读出此前未完整解开的投喂与转运记录。
2. 母亲受害记载、实验批号和旧赐印日期互证，落实白银使者投喂链；莲泉转述西流尔的安排，幽花区分保留皇血的意图与家人的真实代价。
3. 隔离间中检验莲泉两系四套回路：两套永生、两套驭兽仍在，黑血仍会争路；幽花与莲泉重新选择保护彼此。
4. 众人停留冰室与相邻藏书房，证据已齐而后续真相仍待调查；敌人知逃亡却不知冰室坐标，神音、霓虹仍留隐山宫。

### 第一百七十八回：隐山宫的残卷

1. 格兰尔特秘密藏书房：麒零、幽花核对三筒材料的缺页，第一位骑士带来旧天格分藏抄手叶荻的求援；众人限定外出人数，保住冰室位置。
2. 隐山宫旧分藏：麒零与幽花接出被征用视路的叶荻，以蒙眼和切离黑血媒介的反例确认路径保存与捕魂条件，叶荻选择留下证词。
3. 分藏地下小中继：利用空白抄片和魂器分流做有限试验，验证同时整合有承载上限；发生回查后物理截断中继，带走可复制的原始记录。
4. 藏书房：三份材料互证小试结果；暂不能断言全国节点同样脆弱，决定寻找供雾来源与总阵，莲泉仍有反噬风险。

### 第一百七十九回：来自外界的雾

1. 格兰尔特地下旧水廊：叶荻带领幽花、麒零与第一位骑士找到源晶碑文，幽花从皇族旧印中看见垄断魂雾的历史。
2. 水廊废供雾室：自然裂隙、铜灯与支路开关做反证，确认黄金魂雾不由祭司创造；仅断控制支路，保留天然母源。
3. 秘密藏书房：吉尔与艾欧斯以碑文、阵图、实测核验，提出三个相互牵制的寄生节点，确认不能靠杀皇族取得现成能源。
4. 抄录台：幽花选择连同皇族签押公开旧账；抄手整理公开版本，保存操作细节与冰室地址的保密副本。

### 第一百八十回：被替换的人

1. 藏书房：黑血实验记录中的改号、伤痕和原始收尸账互证呪夜借苍白少年躯壳重塑，麒零反对把记忆片段当完整人格。
2. 废供雾室隔离台：以遗留黑血小样对物件的固定反应检验记忆片段与自主选择的区别，莲泉遭回路牵引，试验及时中止。
3. 吉尔床边：记录追索格兰仕黑暗状态与饕餮旧编号，吉尔提供可再验证的身体特征与旧习，不凭思念宣告确认。
4. 冰室：麒零确认银尘本人灵魂是救援前提，停止寻找替代容器；一份带有处刑体系新迭代项的副本被设法送向神音、霓虹。

### 第一百八十一回：更高的堤坝

1. 隐山宫：神音、霓虹收到处刑命令和与之矛盾的淘汰副本，发现执行完任务也无法自保，先保护被扣押的送信抄手。
2. 小视路中继边：霓虹第一次意外短时外放无感，使神音的共享反馈变空白；自身防护降低，第一次承担疼痛，神音带他撤离。
3. 废供雾室：与麒零、幽花会合，在隔离与防护下复核范围、时长和代价，拒绝以折磨霓虹加速进化；局部失稳后物理断路。
4. 藏书房外：神音交出原始命令并同意合作，霓虹用有限言语与动作选择保护旁人，双方保留对旧罪的记忆。

### 第一百八十二回：冰帝的旧约

1. 冰室外密柜：艾欧斯公开四年前冰封银尘的记录、保藏的旧记忆片段及与祭司交易的签押，承认主动切离旧回路与取舍记忆的责任。
2. 藏书房：麒零与幽花质问帝王，艾欧斯交还材料并容许逐项核验，吉尔说明自己并非早知全部秘密。
3. 隔离修复台：以切出的微量旧魂路组织验证新赐印会撕裂修复部位，确认银尘必须永久剥离所有旧魂路；神音与莲泉参与保护，试验付出具体损伤。
4. 冰室：众人决定将完整记忆归还给银尘本人，再由他选择方案；莲泉提出拆除永生闭合回路的一次排异可能，暂未实施。

### 第一百八十三回：没有名字的王座

1. 藏书房及旧阵模型：吉尔通过遗留封印实物说明四年前囚禁的组合限制，承认自己的断控失败，拒绝把救援写成争夺新王座。
2. 废供雾室：麒零用有限数量魂器试接多路模型，核实七度无限魂器作为调流接口的用途和操控上限，测试即时停止。
3. 旧兽运道：骑士带回饕餮运输印记与伤痕拓片，吉尔将旧伤与旧习互证，确认格兰仕化兽且仍被驱使。
4. 宫外会面处：漆拉以交出幽花换新爵位诱使麒零，麒零拒绝；名单让漆拉动摇，他仍不交出核心通路。

### 第一百八十四回：归来的声音

1. 冰室：肉身有限修复与完整灵魂隔离维护争取一次短暂清醒，银尘认出麒零，未恢复魂力或灵犀。
2. 冰台旁：银尘接回保藏记忆，自己辨认与四年前的遭遇；麒零从代他决定转向告知风险，艾欧斯当面承认责任。
3. 冰室：银尘听取永久剥离魂路与再次赐印的不可逆后果，自愿选择活下去，以日常愿望给麒零具体约定。
4. 重新封冰：银尘回到隔离冰封，麒零留下书面同意与记忆核验记录；众人准备公共救援和核心行动。

### 第一百八十五回：最后一封红讯

1. 格兰尔特抄录点与雷恩接应处：天格地方分路把可复制罪证分路公开，包含幽冥、特蕾娅、皇族旧罪；小核桃与祖母面对实际转移困境。
2. 秘密藏书房：三个节点的坐标、联动与有限反制证据齐备，众人确定分工、撤民通道和失败后的退路。
3. 宫外及隐山宫：三祭司下达清除城市与征用皇血的红讯；漆拉发现名单将他列作待销毁材料，尚未投诚。
4. 冰室与出发廊：麒零、吉尔准备进入核心，幽花与莲泉护阵，神音霓虹护民，艾欧斯统筹撤离并守冰室；莲泉黑血尚存，银尘知情同意后仍冰封。

### 第一百八十六回：雾中的城

1. 雷恩港：清除令驱使供雾支路反向征用城民，骑士依公开阵图拆开码头中继，给普通人留下撤离道路。
2. 雷恩南城：神音与霓虹护送小核桃和祖母，受控卫兵封路；两人救出车下伤者，从旧郡王府取回布娃娃，交雷恩外城救济所登记，再依安全路线换马赶回格兰尔特西眼塔。
3. 核心外围：麒零与吉尔检查三处分路，发现饕餮被强制驱往核心；左肩向内弯的旧骨伤、护左侧让半步的旧习与运输原签互证，确认格兰仕身份。
4. 宫城北门：漆拉在迭代命令中看到自己的最终处理次序，尝试退路却发现坐标已被锁入控制阵。

### 第一百八十七回：看不见的战场

1. 西眼塔：麒零接入有限魂器分流，神音保护中继，霓虹先向近处一名守卫和神音外放无感；第七息撤回神音一侧，第十息全部结束，共享网把局部空白重复复制。
2. 塔顶内侧：寒霜似调入更多旧路径维持整合，反使同组支路超载；神音承受反击，麒零付出魂器损毁后切开中继。
3. 核心外廊：吉尔阻挡被驱入核心的饕餮，视线控制失效后逐根截断黑暗节点，验证它就是格兰仕。
4. 塔下及外廊：确认寒霜似死亡，格兰仕无法恢复为人，在故人陪伴下停止受苦；吉尔收殓，不以死亡抹去多年折磨。

### 第一百八十八回：黑血的尽头

1. 凝腥洞穴下层：幽花与莲泉查出母线和三具傀儡容器，寒霜似死后黑血改为直接夺取莲泉身体；幽花只以有限供血稳住护阵。
2. 母线前：莲泉知情拆除西流尔永生闭合回路，利用回路争夺制造一次排异通道，保住原驭兽回路；幽花与骑士协助物理切线。
3. 容器区：呪夜试图借残存载体接续，母线断后躯壳与记忆移植一起崩解；幽冥、特蕾娅傀儡停止动作，遗体被取出。
4. 出口：明确莲泉永久失去永生、寿命有限，伤口不再即刻修复；她仍能与魂兽建立联系，幽花扶她离开。

### 第一百八十九回：白银囚笼

1. 水晶房间外层：麒零、吉尔与赶来的艾欧斯依既有阵图逐段试探，分清天然源晶、皇血征用支路和祭司寄生控制层。
2. 躯体容器前：强制接入皇血的实际反应与旧试验编号互证，确认祭司欲改变共享上限归属，以重塑身体离开水晶。
3. 档案槽：众人从祖辈王爵迭代记录看见试验及资源分配，艾欧斯承认帝王曾为自身地位接受交易，保留罪证。
4. 核心三叉口：确认外部中继、母线虽已断，核心三根控制返回路仍须同步切除；分配麒零、吉尔、艾欧斯的有限任务。

### 第一百九十回：谁可以离开

1. 水晶房间外层：漆拉提出换取撤离与不被追捕的条件，麒零和吉尔要求他交出坐标，明确不删去真实背叛记录。
2. 三叉通路：祭司将转移支路接向漆拉旧坐标，普通通道被折回；漆拉承认当年设计囚笼，自行开出未登记的逃路。
3. 位面锚点：漆拉在独自可逃时选择留下，为三路行动保持出口，逐个封死敌人的转移坐标。
4. 通路关闭：最后两端撤净后，漆拉封住仍穿过自己身体的锚线，死于位面崩塌；幸存者保留背叛与最后选择的完整记录。

### 第一百九十一回：最后一把魂器

1. 三个断口：吉尔守西眼塔基座，艾欧斯在凝腥洞穴固定控制根，麒零在水晶房间分开三路返流；普通传信者逐段送出准备信号。
2. 中央接口：祭司以既有征用支路反扑，麒零按前期试验把有限储存魂器依次耗在分流中，无法凭天赋无限再生。
3. 同步断线：吉尔、艾欧斯承担返流与伤害，麒零以最后一柄可战魂器切中央接口；三根返回路在同一承压窗口断掉。
4. 核心之后：祭司与自锁控制层一起毁灭，天然源晶和皇血共享上限保留；众人实地检查断口、救出耗尽魂力的麒零。

### 第一百九十二回：无爵之人

1. 战后第三日冰室：众人依银尘已同意的方案进行最后剥离，治疗者修补肉身，吉尔护完整灵魂，艾欧斯仅维持局部冰封，各有伤势限制。
2. 第四日苏醒：银尘稳定归身，完整记忆与人格得到确认；既往微量试验和实际承载损伤证明他永久不能接受赐印，灵犀也不恢复。
3. 宫城告示廊：三份证据、皇族旧约和处刑名单同时公开，艾欧斯承责接受监督，解除红讯与侵蚀者培育，救济和补偿开始执行。
4. 城外墓地与冰室门口：死者分别安葬，记录漆拉背叛及最后选择；麒零与银尘以普通人的身体开始一起走路。

### 第一百九十三回：福泽的春天

1. 次年初春福泽驿站：麒零与银尘回到普通生活，一同洗衣、做饭和接待客人；银尘永久无魂力，麒零仍在构建期，有限力量只承担力所能及的事情。
2. 雷恩救济所与渡口：幽花继续公开资料和救助，莲泉以有限生命驭兽、照顾伤者；神音霓虹选择自在出行，保持少言，不再以折磨换取成长。
3. 格兰尔特及海边：艾欧斯在监督下承担治理与旧罪，吉尔拒绝王座、带着伤离开权力中心，在港边住下。
4. 福泽驿站：道路解冻后，雷恩救济所按祖孙安置地址送达布娃娃，小核桃亲手领回；银钩归于银尘，雪刺由麒零照管，众人吃饭，完整收束。
